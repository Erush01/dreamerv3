# DreamerV3 RTX 5070 GPU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the checkout install consistently and perform a real DreamerV3 training update plus checkpoint reload on the RTX 5070.

**Architecture:** Update the declared Python dependency set for CUDA 13 and NumPy 2, then migrate the handful of `jax.jit` calls to the modern keyword-only API. Test the actual agent against the built-in synthetic environment, fixing only failures reproduced on that path.

**Tech Stack:** Python 3.12, JAX 0.11.2 CUDA 13, NumPy 2.x, DreamerV3, RTX 5070.

**Spec:** `docs/superpowers/specs/2026-09-26-rtx5070-dreamerv3-design.md`

## Global Constraints

- Host: Python 3.12, RTX 5070 (SM 12.0), NVIDIA driver 616.56.
- Target: matched JAX 0.11.2 CUDA 13 stack with NumPy 2; no old CUDA 12 or NumPy 1 constraints.
- Verification uses `dummy_disc`; Atari ROMs, Minecraft, and optional external environments are outside scope.
- Success means conflict-free `pip check`, a CUDA device, finite loss after at least one actual optimizer update, and checkpoint save/reload.
- Do not touch unrelated GPU processes, optional environment code, or the legacy Dockerfile.
- Do not commit without explicit user authorization; keep generated logs outside the checkout.

## Review Focus

- Package installation after editable install must not silently downgrade JAX: Task 1 checks `pip check` and prints installed JAX/NumPy versions.
- GPU preallocation must not make a shared 12 GB GPU appear broken: Task 3 runs with `XLA_PYTHON_CLIENT_PREALLOCATE=false` and reports VRAM exhaustion separately.
- Random-agent execution must not be mistaken for an optimizer update: Task 3 explicitly uses `random_agent=False` and inspects a finite train metric.
- A fresh process must reload the saved checkpoint: Task 3 reruns the same logdir with a higher step limit.
- Ancillary ROM-dependent environments must not be claimed validated: Task 3 documents the synthetic-task scope with the result.

**Interfaces:**
- Consumes: `jax.jit(fun, *, in_shardings=..., out_shardings=..., static_argnums=..., donate_argnums=...)`.
- Produces: unchanged model/sharding semantics with modern JAX-compatible call sites.

- [ ] **Step 1: Add a failing focused test.** Create `embodied/tests/test_jit_compat.py`:
  ```python
  import ast
  import pathlib
  import unittest

  ROOT = pathlib.Path(__file__).resolve().parents[2]

  class TestJitCalls(unittest.TestCase):
    def test_no_positional_jit_options(self):
      for path in ('embodied/jax/transform.py', 'embodied/jax/agent.py',
                   'embodied/jax/internal.py'):
        tree = ast.parse((ROOT / path).read_text())
        for node in ast.walk(tree):
          if (isinstance(node, ast.Call) and isinstance(node.func, ast.Attribute)
              and isinstance(node.func.value, ast.Name)
              and node.func.value.id == 'jax' and node.func.attr == 'jit'):
            self.assertLessEqual(len(node.args), 1, f'{path}:{node.lineno}')
  ```

In `agent.py:173-181`, name the existing second and third arguments `in_shardings=` and `out_shardings=`. In `internal.py:280-282`, name those same arguments.
